# Conclusion and Lessons Learned

## Conclusion

This project successfully demonstrated the implementation of an enterprise-style IT support environment using ServiceNow and Microsoft Active Directory.

A range of common IT support tasks were completed using structured incident management processes, including account management, password administration, shared folder access, user provisioning and software installation.

Each incident followed a consistent workflow consisting of investigation, implementation and verification, with supporting evidence recorded throughout the project. A knowledge article was also created to demonstrate the importance of maintaining documentation and supporting future incident resolution.

Overall, this project strengthened practical experience with ServiceNow, Active Directory and Windows administration while reinforcing the value of structured troubleshooting, accurate documentation and professional IT support practices.

---

## Lessons Learned

Throughout this project, valuable practical experience was gained in managing common IT support scenarios within an enterprise environment.

Key lessons learned include:

- Applying the complete incident management lifecycle using ServiceNow.
- Creating and managing Active Directory domain user accounts.
- Troubleshooting authentication and account-related issues.
- Managing shared folder permissions and user access.
- Performing software installation and post-installation verification.
- Producing technical documentation supported by implementation evidence.
- Following consistent troubleshooting and verification procedures before resolving incidents.
- Understanding the importance of knowledge management in supporting efficient IT service delivery.

Completing this project also reinforced the importance of clear communication, accurate record keeping and structured problem-solving when supporting users within a Windows domain environment.

---

The completed lab demonstrates practical experience across the full IT support workflow:
