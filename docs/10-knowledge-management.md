# Knowledge Management

## Overview

To support consistent service delivery, a knowledge article was created documenting the standard process for creating a new Active Directory user account.

The article provides IT technicians with a repeatable procedure for provisioning new domain users, helping to improve consistency and reduce onboarding time.

---

## Knowledge Article Creation

The knowledge article was created within ServiceNow to document the Active Directory user provisioning process used during the project.
