# Lab Environment

## Infrastructure

The project was implemented using the following infrastructure:

| Component | Specification |
|---|---|
| Service Management Platform | ServiceNow Personal Developer Instance |
| Domain Controller | Windows Server 2025 (DC01) |
| Client Computer | Windows 11 Enterprise (PC01) |
| Hypervisor | VMware Workstation Pro |
| Operating System | Windows 11 |
| Browser | Google Chrome |

---

## Technologies

The following technologies were used throughout the project:

- ServiceNow
- IT Service Management (ITSM)
- Windows Server 2025
- Active Directory Domain Services (AD DS)
- Windows 11 Enterprise
- DNS
- Group Policy
- VMware Workstation Pro
