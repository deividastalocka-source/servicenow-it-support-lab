# Software Installation Incident

## Incident INC0010013 – Software Installation

### Incident Summary

Michael Brown from the Finance department contacted the IT Service Desk requesting the installation of 7-Zip to enable the extraction of compressed project files.

The software was not available on the user's workstation. The request was investigated, the application was installed successfully and functionality was verified before the incident was resolved.

---

## Investigation

### Purpose

Investigate the user's software request and confirm that the required application was not installed on the workstation.

### Procedure

- Reviewed the incident details in ServiceNow.
- Changed the incident state to In Progress.
- Verified the user's software requirements.
- Confirmed that 7-Zip was not available on the workstation.
- Approved the software installation.

### Verification

The workstation was confirmed to require the installation of 7-Zip before the user could access compressed files.

---

## Resolution

### Purpose

Install the requested software and verify that it was successfully deployed to the user's workstation.

### Procedure

- Downloaded the latest version of 7-Zip.
- Installed the application using the default installation settings.
- Verified that the installation completed successfully.
- Confirmed that 7-Zip was correctly integrated into the Windows context menu.
- Updated and resolved the ServiceNow incident.

### Implementation Evidence

### Verification

The software installation completed successfully, and 7-Zip was verified to be operational through the Windows Explorer context menu, confirming that the application had been installed correctly and was available for user access.
