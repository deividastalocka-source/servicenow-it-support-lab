# Project Overview

## Executive Summary

This project presents the implementation and validation of a ServiceNow Personal Developer Instance (PDI) configured to simulate a realistic enterprise IT Service Desk environment.

Building upon the Enterprise Active Directory Infrastructure Lab, this project demonstrates how ServiceNow is used to manage, investigate and resolve common IT support requests within an enterprise Windows domain. Rather than focusing solely on configuring the platform, the project simulates the day-to-day responsibilities of an IT Support Analyst by handling realistic incidents, service requests and user administration tasks.

The implementation demonstrates the complete support lifecycle, from ticket creation and categorisation through investigation, resolution and closure. Common enterprise scenarios such as password resets, account lockouts, new user provisioning, security group management, shared folder permissions and software requests are completed using the existing Active Directory environment.

Each activity is documented with supporting screenshots and technical explanations to demonstrate practical experience with both Windows infrastructure administration and IT Service Management.

---

## Introduction

### Project Overview

ServiceNow is one of the world's leading IT Service Management (ITSM) platforms and is widely used by organisations to manage incidents, service requests, knowledge management and day-to-day IT support operations.

The purpose of this project is to demonstrate how ServiceNow can be used alongside an existing Windows Server Active Directory environment to support enterprise users through structured IT support processes.

Unlike the previous project, which focused on building enterprise infrastructure, this implementation focuses on operating and supporting that infrastructure using ServiceNow. Realistic support requests are created, investigated and resolved using the Active Directory environment previously deployed.

Together, both projects demonstrate the relationship between enterprise infrastructure and enterprise IT support.

---

## Project Objectives

The primary objectives of this project are to:

- Deploy and configure a ServiceNow Personal Developer Instance.
- Configure a realistic enterprise IT support environment.
- Create users, assignment groups and support workflows.
- Manage incidents and service requests using ServiceNow.
- Resolve support requests using the Enterprise Active Directory Infrastructure Lab.
- Produce professional technical documentation supported by screenshots.

---

## Scope

This project focuses on ServiceNow IT Service Management (ITSM) functionality most relevant to entry-level IT Support and Service Desk roles.

The implementation includes incident management, service requests, assignment groups, user administration, knowledge management and reporting while using the previously created Active Directory environment to complete technical support tasks.

Advanced ServiceNow modules such as ITOM, HRSD and CSM are outside the scope of this implementation.
