# Enterprise ServiceNow IT Support Lab

## Overview

This project demonstrates the implementation of an enterprise-style IT Support environment using ServiceNow IT Service Management (ITSM) integrated with a Windows Server Active Directory domain.

Built as a continuation of my Enterprise Active Directory Infrastructure Lab, this project simulates the day-to-day responsibilities of an IT Support Technician by resolving realistic enterprise support requests using ServiceNow together with Active Directory administration tools.

---

## Objectives

- Deploy a ServiceNow Personal Developer Instance (PDI)
- Configure an enterprise IT support environment
- Manage realistic incidents and service requests
- Integrate ServiceNow with an existing Active Directory lab
- Demonstrate common IT support procedures
- Produce professional technical documentation
